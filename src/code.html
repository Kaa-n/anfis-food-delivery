Deskripsi & Tujuan Sistem

Sistem ini mengestimasi waktu tiba pengantaran makanan secara adaptif menggunakan arsitektur Adaptive Neuro-Fuzzy Inference System (ANFIS). Model memetakan interaksi non-linear antara lima variabel operasional utama—jarak tempuh restoran ke pelanggan, waktu persiapan dapur, pengalaman kurir, tingkat kemacetan lalu lintas, dan kondisi cuaca—ke dalam 32 aturan fuzzy Sugeno Orde-1 dengan fungsi keanggotaan Gaussian yang dilatih secara hibrida.

Informasi Sistem, Parameter Akhir & Panduan Penggunaan

  1. Beranda & Prediksi Utama: Memprediksi waktu pengantaran menggunakan kondisi operasional deterministik berbasis seed atau input jarak manual.
  2. Dataset & Preprocessing: Mengunggah atau memuat dataset CSV lokal, membersihkan nilai hilang, dan membagi data latih (80%) serta uji (20%).
  3. Pelatihan Model (Training): Mengatur epoch, learning rate, dan regularisasi LSE untuk melatih parameter premis dan konsekuen ANFIS.
  4. Simulasi & Inspeksi 5 Lapisan: Menguji skenario bebas dan memvalidasi derajat keanggotaan Gaussian hingga agregasi 32 aturan Sugeno.
  5. Evaluasi Model: Mengukur performa generalisasi model pada data uji menggunakan metrik RMSE, MAE, R², serta grafik aktual vs prediksi.
